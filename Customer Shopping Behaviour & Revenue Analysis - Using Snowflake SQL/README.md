# Customer Shopping Behaviour & Revenue Analysis

### Project Overview
Customer Shopping Behaviour & Revenue Analysis is a data analytics project built using Snowflake, SQL, and Cortex Analyst to analyze customer transactions, purchasing patterns, revenue performance, product categories, brands, locations, payment methods, online stores, gender, age groups, and monthly sales trends.

The project transforms raw customer shopping transaction data into meaningful business insights. Snowflake SQL is used for data ingestion, transformation, analysis, and identifying key business metrics, while Snowflake Cortex Analyst enables natural-language analysis of the data through a semantic view containing metrics, dimensions, and verified queries.

The project helps an e-commerce/retail business understand customer behaviour, revenue performance, product trends, and sales patterns through both SQL-based analysis and natural-language business questions.

### 🛠️ Tools & Technologies

Snowflake – Cloud data warehouse

SQL – Data analysis and business insights

Cortex Analyst – Natural-language data analysis 

CSV – Source data
